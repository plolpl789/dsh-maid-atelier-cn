# 深海女仆工坊 · 社区增强版

给 **DeepSeek Harness（DSH）** Web 界面使用的鲸鱼娘女仆皮肤。

本仓库是 [Small-tailqwq/dsh-deep-whale](https://github.com/Small-tailqwq/dsh-deep-whale) 中 `maid-atelier` 皮肤的**社区增强版**，基于上游 **v0.1.8**。上游的全部功能都在，另外把一组日常使用中很顺手的定制能力搬了过来。

> 本版本与上游共用同一个皮肤 ID（`ui-skin-maid-atelier`）与包名，**请勿与上游版同时安装**，二者选其一。

---

## 与上游的差异

### 1. 会话头部三键同排

「对话」「轨迹」「皮肤」三枚胶囊按钮整齐排列，Session Log 对齐到右侧同行。三枚按钮共用同一套圆角与激活态样式。

### 2. 背景换图

- 上传任意图片替换对话区背景，内置宫殿背景作为兜底
- 按主题分槽：浅色主题存「白天」，深色主题存「夜晚」
- 三种铺法：**铺满**（cover）／**适中**（contain）／**拉伸**（fill）
- 图片存 IndexedDB，刷新、重启都不丢
- 设置页顶部有「当前背景」实时预览，与真实背景同一个变量源

### 3. 字体细粒度设置

7 个区域，每个都可以独立选字号（9 档：默认／12–24px）与字体（14 款）：

| 区域 | 默认 |
|---|---|
| 工作区 | 14px |
| 面板区 | 13px |
| 聊天正文 | 跟随官方 |
| 代码块 | 跟随官方 |
| 工具结果 | 跟随官方 |
| 系统标签 | 跟随官方 |
| 标题 | 跟随官方 |

图标、代码块、弹层不会被误改。字体列表已按 Windows 实装字体校对过（楷体／仿宋／黑体／等线／华文系列／Noto 系列等）。

### 4. 角色浮窗

- 两位女仆立绘装进浮窗系统：**拖拽移动、滚轮缩放、显示／隐藏、锁定、删除**
- 位置与尺寸按**对话区比例**存储，窗口拉伸、右栏开合时随之自适应缩放
- 支持上传任意图片作为浮窗
- 锁定后不吃鼠标事件，可以点穿到背后的界面

### 5. 界面修正

- 女仆立绘强制不透明（上游会按屏幕宽度把她们淡化到 0.66～0.9）
- 拖拽浮窗时不再选中页面文本（消除蓝色选框）
- 加载页不再出现「先散开、再瞬移」的怪现象
- 头部胶囊化规则限定在会话头部内，不会误伤插件市场的分页条

## 安装

### 从本仓库安装

```sh
npx -y @deepseek-ai/dsh plugin --profile web add "<本仓库地址>"
```

安装完成后重启一次 DSH，刷新浏览器。

### 本地开发

```sh
git clone <本仓库地址>
npx -y @deepseek-ai/dsh plugin --profile web add "link:<本地路径>"
```

本皮肤是**纯展示层客户端插件**：不注入服务、不发网络请求、不触达模型调用。卸载即完全复原。

## 使用

皮肤启用后，会话头部会出现第三枚按钮 **「皮肤」**，点开是三页设置中心：

- **背景** — 更换图片 / 恢复内置 / 铺法三选 / 当前背景预览
- **字体** — 7 区域字号与字体 / 恢复默认
- **浮窗** — 添加图片 / 大小滑块 / 显隐 / 锁定 / 删除

浮窗操作：**按住拖动**移动位置，**滚轮**缩放（120–1500px），面板里可锁定或删除。

## 关于源码

本版本的功能实现于上游的**构建产物** `lib/client.js`（因为上游已切换到 tsdown 构建，重跑构建需要完整脚手架与资源管线）。因此：

- ✅ `lib/` 可直接安装使用
- ⚠️ `src/` 尚未同步这些改动，重新构建会丢失

源码回写与上游对齐正在整理中，完成后会补上对应的 `src/` 改动。
